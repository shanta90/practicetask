# AGENTS

This repository is a minimal JavaScript practice project with a single source file:

- `practice.js`

There is no `package.json`, no build system, and no test configuration. The file is intended for simple Node.js-based practice and learning exercises.

## Guidance for AI coding agents

- Focus on `practice.js` only.
- Preserve the existing task scope and meaning of the file unless the user explicitly asks for new functionality.
- Fix syntax errors, logic bugs, and obvious runtime issues.
- Prefer clean, idiomatic modern JavaScript without introducing unrelated dependencies or frameworks.
- If you refactor, keep the behavior consistent with the demonstrated examples.
- Do not create additional project scaffolding unless the user requests it.
- Use `node practice.js` as the natural execution model.
